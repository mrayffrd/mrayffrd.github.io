# Pop It Game - Full Stack Free Web Game

Game web saling terhubung (Game, Inventori, Gacha, Profile) dengan backend Google Sheets + Apps Script.

**100% Gratis** • Data tidak hilang • Edit konten lewat Spreadsheet

## Cara cepat mulai

Baca file **SETUP.md** untuk panduan lengkap langkah demi langkah.

Ringkas:
1. Buat Google Spreadsheet
2. Paste kode dari `AppsScript.gs` ke Apps Script
3. Deploy sebagai Web App → copy URL
4. Tempel URL ke `script.js` (variabel `API_URL`)
5. Buka `index.html` atau host foldernya

## Fitur

- Login / Register
- Game Pop-It (10 klik = 1 Mora / 1 Credit)
- Inventori + Redeem kode unik
- Zero Gacha (Credit) & Infinite Gacha (Mora)
- Pet otomatis menghasilkan mata uang
- Banner / background profile
- Chat global (auto hapus 3 jam)
- Semua item & rate bisa diedit di Google Sheet tanpa ubah coding
